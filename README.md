# By Sez — UGC Portfolio

Portfolio site for By Sez: UGC for travel, hospitality and lifestyle brands.

Live site (once GitHub Pages is enabled): https://sarahchor20-glitch.github.io/Claude/

## Editing
- All content is in `index.html`. Edit it on GitHub (pencil icon) and commit; the site updates in about a minute.
- Videos live in `videos/` (MP4, H.264, 720px wide, each with a `.jpg` poster frame).
- Photos live in `images/`. `images/preview.jpg` is the image shown when the link is shared.
- See the "QUICK EDIT GUIDE" comment near the top of `index.html`.
- If the site address changes (e.g. the repo is renamed), update the `og:url`, `og:image` and `twitter:image` URLs in `index.html`.
